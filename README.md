# Lumaya — Landing Page Click Dummy

A single-file HTML/CSS/JS prototype of the Lumaya marketplace landing page, implementing:

- **Three-entry-point funnel** (header nav · adaptive search · curated cards) per `landing-page.md`
- **Tabbed multi-product search bar** (All · Events · Retreats · Trainings) with adaptive fields per tab, location-aware defaults, and live URL preview per `search-bar.md`
- **Full launch category sets** (12 event · 10 retreat · 6 training + fast-follow) per `seo-research.md`
- **Lumaya visual identity** — Lora + Inter typography, warm-neutral palette, no mystical iconography, photography-placeholder convention

Single `index.html`. No build step. Open the GitHub Page to interact.
